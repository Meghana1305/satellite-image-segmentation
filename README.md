# Satellite Image Segmentation Using U-Net

## 1. Project Overview

This project focuses on understanding semantic segmentation of satellite images using the U-Net deep learning architecture.

The project was explored as part of AI/ML training to understand how deep learning techniques can be applied to satellite image analysis.

## 2. Project Objectives

- Understand the fundamentals of satellite image segmentation.
- Explore the U-Net architecture for semantic segmentation.
- Understand how images and their corresponding masks are used in segmentation.
- Learn basic image preprocessing concepts.
- Understand segmentation evaluation metrics.

## 3. About U-Net

U-Net is a Convolutional Neural Network (CNN) architecture commonly used for semantic image segmentation.

It consists of two main parts:

- **Encoder:** Extracts important features from the input image.
- **Decoder:** Reconstructs the segmentation map using the extracted features.

Skip connections help transfer spatial information from the encoder to the decoder.

## 6. Evaluation Metrics

The following metrics were studied for understanding segmentation performance:

- **Dice Score:** Measures the overlap between the predicted mask and the ground-truth mask.
- **Intersection over Union (IoU):** Measures the intersection relative to the union of the predicted and ground-truth regions.
